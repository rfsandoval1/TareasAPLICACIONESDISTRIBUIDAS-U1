# Simulación de Ejecución Concurrente: Preparación de Desayuno Chevere concurrente

Este proyecto demuestra un proceso de la vida diaria (**preparar diferentes elementos de un desayuno**) utilizando Python y `asyncio` bajo un modelo de **ejecución concurrente**.

## Requisitos previos

- [Docker](https://www.docker.com/) instalado en tu equipo.
- [Docker Compose](https://docs.docker.com/compose/) instalado.

## ¿Cómo ejecutar el script con Docker?

Puedes ejecutar el script utilizando Docker Compose directamente con los siguientes pasos en tu terminal:

1. Clona este repositorio o descarga los archivos en una carpeta.
2. Abre tu terminal en la raíz del proyecto.
3. Ejecuta el siguiente comando para construir y correr el contenedor:

```bash
docker compose up --build
```
